# Repositório Jurídico — Steven Edward Santos Duarte

> **Direito • Tecnologia • Pesquisa Jurídica**

Este repositório é a base técnica de um projeto que aproxima **pesquisa jurídica, documentação e tecnologia**.

A experiência foi separada em duas camadas para públicos diferentes:

- **Site público / cartão digital:** pensado para qualquer pessoa conhecer o percurso, o perfil e os contatos sem precisar usar o GitHub.
- **Portfólio:** uma apresentação visual e acadêmica dos projetos, voltada principalmente a estudantes, professores e profissionais do Direito.
- **Repositório:** espaço técnico destinado a código, estrutura dos projetos, modelos, fluxogramas e documentação.

## Resumos visuais

Os primeiros materiais organizam:

1. fluxo de pesquisa jurídica;
2. estrutura de uma tese jurídica;
3. modelo para conferência de prazo processual.

Os modelos são deliberadamente estruturais quando a fonte disponível não contém uma situação jurídica concreta. O projeto não inventa teses, prazos ou fundamentos para preencher diagramas.

**Regra editorial:** um fluxograma é uma ferramenta de síntese e estudo; a fonte jurídica original permanece necessária para fundamentar qualquer conclusão jurídica.

## Publicação

O site é publicado pelo GitHub Pages através de `.github/workflows/pages.yml`.

A branch `main` é a fonte do conteúdo publicado. Alterações no código podem disparar uma nova publicação automaticamente.
