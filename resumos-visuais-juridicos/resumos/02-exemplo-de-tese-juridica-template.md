# 02 — Modelo visual de tese jurídica

> **Template:** substituir os campos entre colchetes por conteúdo efetivamente pesquisado e citar as fontes utilizadas.

```mermaid
flowchart TD
    A["[Problema jurídico]"] --> B["[Fatos relevantes]"]
    B --> C["[Questão jurídica]"]
    C --> D["[Norma / fonte primária]"]
    D --> E{"[Há interpretação controvertida?]"}
    E -- "Não" --> F["[Regra aplicável]"]
    E -- "Sim" --> G["[Tese A]"]
    E -- "Sim" --> H["[Tese B]"]
    G --> I["[Fundamentos + fontes]"]
    H --> J["[Fundamentos + fontes]"]
    I --> K["[Aplicação ao caso]"]
    J --> K
    F --> K
    K --> L["[Conclusão]"]
```

## Estrutura acadêmica

### 1. Problema
[Descrever o problema de forma objetiva.]

### 2. Questão jurídica

### 3. Fontes
- [Lei / regulamento]
- [Jurisprudência]
- [Artigo / livro]
- [Fonte institucional]

### 4. Tese ou entendimento

### 5. Contra-argumentos
[Registrar interpretações alternativas e respectivas fontes.]

### 6. Aplicação

### 7. Conclusão
[Conclusão delimitada ao problema pesquisado.]
