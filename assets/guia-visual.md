# Guia visual

## Linguagem

O projeto usa uma estética de **documentação técnica + pesquisa jurídica**:

- títulos curtos;
- blocos de informação;
- fluxos de decisão;
- tabelas de conferência;
- destaque para fontes;
- separação entre regra, exceção e aplicação.

## Convenção dos fluxogramas

- Retângulo: etapa ou informação.
- Losango: decisão/pergunta.
- Setas: sequência lógica.
- Ramificações: hipóteses alternativas.
- Último bloco: conclusão ou ação.

## Regra editorial

Não transformar um fluxograma em autoridade jurídica. O diagrama é uma ferramenta de síntese; a fonte original permanece necessária para verificar a regra.
